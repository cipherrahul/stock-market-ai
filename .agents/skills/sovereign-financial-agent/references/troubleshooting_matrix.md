# Troubleshooting Matrix: Sovereign AI Platform

| Symptom / Error Message | Root Cause | Immediate Remediation |
|---|---|---|
| `connect ECONNREFUSED 127.0.0.1:5432` | PostgreSQL is not running or port 5432 is blocked. | 1. Check service: `Get-Service postgresql*` in PowerShell.<br>2. Start service or launch docker: `docker-compose up -d postgres`.<br>3. Verify connection: `psql -U trading_user -d trading_platform`. |
| `Encryption Failed. Ensure SYSTEM_ENCRYPTION_KEY is 32 characters` | `SYSTEM_ENCRYPTION_KEY` in `.env` is either missing, shorter, or longer than 32 ASCII characters. | 1. Open `.env`.<br>2. Ensure `SYSTEM_ENCRYPTION_KEY` is exactly 32 bytes (e.g. `sovereign_2026_master_key_secret_32`).<br>3. Re-run `npx tsx scripts/encrypt_token.ts`. |
| `KafkaJSConnectionError: Connection error: connect ECONNREFUSED 127.0.0.1:9092` | Kafka broker is down or Zookeeper has not initialized. | 1. Ensure Zookeeper starts before Kafka.<br>2. Run `docker-compose up -d zookeeper kafka`.<br>3. Check logs: `docker-compose logs kafka`.<br>4. Note: If running locally without Docker, point `KAFKA_BROKER` to an active Kafka cluster or use an in-memory/mock fallback in test environment. |
| `STRIPE_FAILURE: No API key provided` or `sk_test_mock` error | `STRIPE_SECRET_KEY` is not set in `.env` or set to default mock string in production. | 1. In development, the mock gateway logs a fallback warning.<br>2. In staging/production, set `STRIPE_SECRET_KEY=sk_test_...` in `.env` or Docker secrets.<br>3. Verify bank bridge balance in `portfolio-service`. |
| `Signal confidence below threshold or HOLD. Bypassing execution.` | AI Engine emitted signal with confidence < 75% or `signal === 'HOLD'`. | Normal behavior. Sovereign Alpha Hunter enforces an institutional risk threshold (>= 75% confidence) before submitting orders to Smart Order Router. |
| `EADDRINUSE: address already in use :::3000` | Port 3000 (API Gateway) is already occupied by a previously spawned Node.js process. | 1. Find process: `netstat -ano \| findstr :3000`<br>2. Kill process: `taskkill /F /PID <PID>` in Windows CMD/PowerShell.<br>3. Or kill all node processes: `taskkill /F /IM node.exe /T`. |
| `401 Unauthorized: jwt expired / invalid token` | JWT token expired (default 24h) or mismatch between `JWT_SECRET` in `api-gateway` and `auth-service`. | 1. Verify that `JWT_SECRET` is identical across `.env`, `apps/gateway/.env`, and `services/auth-service/.env`.<br>2. Re-authenticate via `/api/v1/auth/login` to obtain fresh bearer token. |
| `TimescaleDB hypertable error on market_history` | Regular PostgreSQL table exists without TimescaleDB extension enabled. | 1. The schema contains fallback primary keys `(symbol, time)`.<br>2. If TimescaleDB extension is present, run `SELECT create_hypertable('market_history', 'time', if_not_exists => TRUE);`. |
| `Liquidity Service: 14-day Sandbox Hardlock active` | Sandbox safety guard prevents real-money withdrawals during initial 14-day bake period. | 1. Inspect `liquidity-management-service` configuration.<br>2. For testing/demo mode, toggle `SANDBOX_OVERRIDE=true` in environment configuration. |
